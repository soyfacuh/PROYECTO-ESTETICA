# ✨ Lúmina Atelier | Uñas & Pestañas

**Concepto de estética boutique · Portfolio de [Soyfacuh](https://soyfacuh.com)**

Lúmina Atelier es una propuesta de sitio web para un estudio de uñas y pestañas, desarrollada como proyecto de demostración para potenciales clientes. Combina una identidad visual cálida y elegante con una experiencia de navegación intuitiva y un sistema de turnos simulado, para ilustrar cómo una estética puede presentar sus servicios y facilitar el contacto con sus clientas.

> **Aviso:** Lúmina Atelier es una **demo para portfolio y presentaciones comerciales**. La marca, los servicios, horarios, disponibilidad, precios, imágenes y datos presentados son ilustrativos. El sistema de turnos **no confirma reservas reales**, no procesa pagos ni envía datos a un establecimiento.

## 🎯 Objetivo

Exhibir una landing page comercial para un emprendimiento de belleza, centrada exclusivamente en **uñas y pestañas**, con una presentación atractiva, información clara y una experiencia de reserva de muestra.

## 💅 Servicios conceptuales

- **Uñas:** semipermanente, soft gel, kapping, esculpidas y nail art.
- **Pestañas:** lifting, extensiones clásicas, efecto híbrido, volumen y mantenimiento.
- **Galería de inspiración:** fotografías de referencia organizadas por categoría.
- **Valores orientativos:** precios y duraciones de ejemplo, sin validez comercial.

Los tratamientos y contenidos pueden adaptarse a los servicios reales de cada negocio.

## ✨ Diseño y experiencia

- Identidad de estética boutique con una paleta suave y elegante.
- Diseño responsive para computadoras, tablets y celulares.
- Composición visual con fotografías, tarjetas, sombras y detalles de profundidad.
- Navegación por secciones y llamados a la acción para explorar tratamientos y reservar.
- Galería interactiva con filtros de uñas y pestañas y ampliación de imágenes.
- Preguntas frecuentes y presentación del estudio.
- Créditos y enlaces a **Soyfacuh** como desarrollador.

## 📅 Sistema de turnos de demostración

El recorrido permite probar la experiencia de una reserva desde el navegador:

1. Seleccionar una categoría y un tratamiento.
2. Elegir una fecha y un horario de disponibilidad simulada.
3. Completar datos de ejemplo y aceptar el aviso de demostración.
4. Visualizar un resumen y una confirmación **ficticia**.

Esta versión **no dispone de agenda real, base de datos, notificaciones, integración de calendario, cobros ni confirmaciones comerciales**. Los datos ingresados se utilizan para mostrar el resultado en pantalla y no se envían a un servidor.

## 🧪 Una web de demostración

El proyecto está pensado para presentar una propuesta de diseño y funcionalidad en reuniones con clientes o como muestra pública de portfolio. No representa a una estética existente ni debe interpretarse como canal habilitado para contratar tratamientos.

## 💼 Posibles ampliaciones

Para una implementación comercial se podrían incorporar, según las necesidades del negocio y el presupuesto acordado, agenda conectada a una base de datos, gestión administrativa de turnos, confirmaciones por correo o WhatsApp, pagos de señas, recordatorios, disponibilidad real del personal, SEO local y analítica. **Estas funciones son posibilidades futuras, no características de esta demo.**

El sitio puede publicarse como página estática, por ejemplo mediante GitHub Pages, sin instalar dependencias.

1. Descargar y descomprimir el proyecto.
